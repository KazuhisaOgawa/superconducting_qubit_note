# jb buildが通らない時に仮想環境の構築まとめ

了解しました！🙆 仮想環境を使う方法を Mac (zsh) 前提で整理します。
これでプロジェクトごとに環境を分けられるので、jb や pip の衝突問題を回避できます。

⸻

🔹 仮想環境の手順まとめ

1. プロジェクトフォルダに移動

cd ~/path/to/superconducting_qubit_note

2. 仮想環境を作成

python3 -m venv .venv

	•	.venv という名前のフォルダに環境が作られます（任意で変更可）。

3. 仮想環境を有効化

source .venv/bin/activate

	•	プロンプトの先頭に (.venv) が付きます。
	•	これが「仮想環境が有効」なサインです。

4. pip をアップグレード

python -m pip install --upgrade pip

5. Jupyter Book をインストール

python -m pip install jupyter-book

6. ビルドを実行

jupyter-book build ./

もし jupyter-book が見つからない場合は：

python -m jupyter_book.cli build ./

7. 仮想環境の終了

作業が終わったら

deactivate


⸻

🔹 次回以降の使い方
	1.	プロジェクトフォルダに移動
	2.	仮想環境を有効化

source .venv/bin/activate


	3.	jupyter-book build ./ を実行

⸻

👉 この流れで、他のプロジェクトにも .venv を作れば環境を完全に分けられます。
