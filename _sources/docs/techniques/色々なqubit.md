# 様々な超伝導qubit

## 電荷量子ビット（charge qubit）

超伝導アイランド上のクーパー対（電荷 2e）の個数を量子状態として用いる, 最も基本的な超伝導量子ビットで, 別名 Cooper pair box（CPB）とも呼ばれる. 

### 基本構造

図のように, トランズモンと同様にジョセフソン接合と
•	超伝導アイランド（非常に小さい）
•	ジョセフソン接合（外部リードと弱結合）
•	ゲート容量 C_g と ゲート電圧 V_g（電荷を制御）

アイランドが小さいため, 1 個のクーパー対を載せるエネルギーが大きいのが本質.

### 競合する2つのエネルギー

電荷量子ビットの物理は次の競合で決まる. 

充電エネルギー:

$$
\begin{align}
E_C=\frac{(2e)^2}{2C_\Sigma}
\end{align}
$$

•	$C_\Sigma$：アイランドの全容量
•	電荷数 $n$ が良い量子数になりやすい

ジョセフソンエネルギー:

$$
\begin{align}
-E_J\cos\phi
\end{align}
$$

•	クーパー対がトンネルし, 異なる電荷数を混成


### ハミルトニアン（基本式）

$$
\begin{align}
H=4E_C(\hat n-n_g)^2 - E_J\cos\hat\phi
\end{align}
$$

•	$\hat n$：クーパー対数演算子
•	$\hat\phi$：位相演算子（$[\hat\phi,\hat n]=i$）
•	$n_g=\dfrac{C_gV_g}{2e}$：ゲート電荷

### 電荷基底での直感

$|n\rangle=\text{「クーパー対が }n\text{ 個」}$
•	充電項 4E_C(n-n_g)^2 は n ごとの放物線
•	n_g を掃引すると放物線が交差

電荷縮退点（sweet spot）

$n_g=\frac12$
で $|n=0\rangle$ と $|n=1\rangle$ が縮退し, $-E_J\cos\phi$ により避けられた交差が生じる. 

### 2準位有効ハミルトニアン

$|0\rangle$, $|1\rangle$ の部分空間に制限すると

$$
\begin{align}
H_{\rm eff}
=
-\frac12\bigl[\varepsilon(n_g)\,\sigma_z + E_J\,\sigma_x\bigr]\\
\varepsilon(n_g)=8E_C\!\left(n_g-\frac12\right)
\end{align}
$$

•	電圧（n_g）で \sigma_z を制御
•	ジョセフソン結合で \sigma_x を与える
→ 電圧操作が非常に直感的

### 読み出し
•	単電子トランジスタ（SET / RF-SET）
•	共振器を用いた分散読み出し
→ アイランド上の平均電荷を検出

### 最大の弱点：電荷ノイズ
•	背景電荷の揺らぎ（1/f ノイズ）
•	表面欠陥・トラップ起源

結果として コヒーレンス時間が短い（nsオーダー）
→ 実用化の大きな障害

### その後の進化（重要）

電荷量子ビットは単体では不利でしたが、現代超伝導量子ビットの原点です。
•	Transmon：$E_J/E_C\gg1$ にして電荷感度を指数関数的に抑制
•	Xmon / 固定周波数トランズモン：スケーラブル実装

現在主流の超伝導量子計算機は, **「電荷量子ビットをノイズに強くしたもの」** と言える. 

### まとめ（要点）
•	何を量子状態にする？ → クーパー対の個数
•	制御は？ → ゲート電圧
•	強み → 単純・直感的
•	弱み → 電荷ノイズに極端に弱い
•	意義 → Transmon などへの発展の出発点
