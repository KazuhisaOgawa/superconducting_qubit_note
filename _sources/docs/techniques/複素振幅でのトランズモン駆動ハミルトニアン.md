# 複素振幅でのトランズモン駆動ハミルトニアン

$\varOmega$を複素数とする: $\varOmega = |\varOmega|{\rm e}^{{\rm i}\phi}$. 振幅$|\varOmega|$, 位相$\phi$でトランズモンを駆動する場合のハミルトニアンは, 

$$
\begin{align}
\hat{H} 
&= 
\omega_q\hat{a}^\dagger\hat{a} 
+ 
\frac{\alpha}{2}\hat{a}^{\dagger 2}\hat{a}^2
+
|\varOmega|\cos(\omega_{\rm d}t+\phi)(\hat{a}+\hat{a}^\dagger) 
\end{align} 
$$

ここで, 

$$
\begin{align}
|\varOmega|\cos(\omega_{\rm d}t+\phi)
&=
|\varOmega|(\cos\phi\cos\omega_{\rm d}t - \sin\phi\sin\omega_{\rm d}t) \nonumber\\
& = 
|\varOmega|\cos\phi\cos\omega_{\rm d}t - |\varOmega|\sin\phi\sin\omega_{\rm d}t \nonumber\\
& = 
\mathrm{Re}(\varOmega)\cos\omega_{\rm d}t - \mathrm{Im}(\varOmega)\sin\omega_{\rm d}t
\end{align} 
$$

であるので, $\mathrm{Re}(\varOmega)$はcos成分, $\mathrm{Im}(\varOmega)$はsin成分であると理解できる. 

さて, $\exp({\rm i}\omega_{\rm d}t\hat{a}^\dagger\hat{a})$で基底変換すると, 

$$
\begin{align}
\hat{H}' 
&= 
\varDelta_{\rm qd}\hat{a}^\dagger\hat{a} 
+ 
\frac{\alpha}{2}\hat{a}^{\dagger 2}\hat{a}^2
+
|\varOmega|\cos(\omega_{\rm d}t+\phi)
(\hat{a}{\rm e}^{-{\rm i}\omega_{\rm d}t}
+\hat{a}^\dagger{\rm e}^{{\rm i}\omega_{\rm d}t}) \nonumber\\
&= 
\varDelta_{\rm qd}\hat{a}^\dagger\hat{a} 
+ 
\frac{\alpha}{2}\hat{a}^{\dagger 2}\hat{a}^2
+
\frac{\varOmega}{2}\hat{a}
+\frac{\varOmega^*}{2}\hat{a}^\dagger
\end{align} 
$$

となる. これが複素振幅$\varOmega$で駆動されているトランズモンのハミルトニアンである.
